# Punch Club 1 (The Dark Fist) — combat source transcription

- Captured: **2026-08-30**
- Scope: **Punch Club (2016) / The Dark Fist only**. Punch Club 2 data is excluded.

> **Important scope correction:** the PC1 Skills page does **not** say there are 27 skills total. It says **Basic: 24 unlockable nodes; Bear: 27; Tiger: 27; Turtle: 27**. This evidence file therefore does not force a 27-row schema. It records the **105 documented unlockable tree nodes**, plus the four core starting combat abilities Punch/Kick/Block/Dodge.

> **Transcription policy:** numeric facts, formulas, names, requirements and short mechanic facts are preserved. Long source prose is summarized rather than duplicated wholesale. Unknown fields are `null`; no missing value is reverse-engineered from adjacent rows or screenshots. Third-party Chinese labels are stored as *unverified translations*, not claimed as official localization.

### Formula caveats

- `REG = 5 + STM*1.5` is explicitly the value shown on the combat stats page; the wiki says the actual in-fight floating regeneration numbers are smaller and the in-fight algorithm still needs testing.
- `ARM = STM*1.3` is a confirmed stat formula, but the wiki describes straight subtraction/rounding behavior as tentative.
- Dodge formula is explicitly unknown. No verified PC1 critical-hit formula was found.
- The PC1 wiki uses the word “initiative” colloquially when saying a zero-energy knockdown can let the attacker keep initiative; it does **not** provide the numeric initiative/initiative-cost system found on the Punch Club 2 mechanics page.
- Developer reply on Steam: ability slot order does not matter by design. A separate deterministic cursor was not found.
