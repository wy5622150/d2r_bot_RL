# 来源说明

本目录下的 skill 全部原样拷贝自官方 `phaser` npm 包的 `skills/` 目录，
由 Phaser Studio Inc. 随引擎一起发布，MIT 协议。

- 来源包：`phaser@4.2.1`（release "Giedi"）
- 同步方式：`node scripts/sync-phaser-skills.mjs`
- 请勿手工修改这里的文件，升级 phaser 后重跑上面的脚本即可。
